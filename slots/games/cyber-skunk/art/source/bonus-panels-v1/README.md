# Bonus entrance panels v1

Three independent transparent production WebP files, 1600×900, in `art/panels/`: `panel-vent-break`, `panel-overpressure`, `panel-blackout`. Built-in ImageGen originals were proportionally contained on the required canvas with Lanczos resampling; no stretching or cropping. Prompts and hashes are included. Publication uses WebP quality 92 with lossless alpha because large PNG uploads stalled; original PNG masters are preserved locally, not claimed published. Existing prep accepts WebP inputs.

Vent Break shows an elbow vent and one reservoir. Overpressure uses paired reservoirs and a gauge. Blackout Protocol uses a dark breaker housing with one cyan accent. Shared ivory industrial lettering and brass/graphite frame connect these panels to the buy cards. No prices, free-spin counts, awards or odds are embedded; those remain live configuration text. No characters or skunks appear.

`review.jpg` is an asset-only review at 520px and 320px widths on a solid backing, not a browser screenshot. Titles were visually checked at both sizes. Alpha and file integrity checks are in the manifest.
